# 지시서 — 배관 자재 목록에서 관경별 길이 합계 내기

- 발행일: 2026-12-01
- 근거 계획서: `pev/PLAN.md`
- 실행 담당: Codex

## 1. 대상 파일
| 파일 | 할 일 |
|---|---|
| `sum_by_size.py` | 새로 만듦 |
| `sample.csv` | 새로 만듦 — 아래 내용 그대로 |

```
line_no,size,length_m
L-101,2",12.5
L-102,2",8.0
L-103,4",20.0
L-104,4",5.5
L-105,6",3.2
```

## 2. 할 일
1. `sum_by_size.py <csv경로>`로 실행되게 한다. 인자가 없으면 사용법을 출력하고 종료 코드 2.
2. 표준 라이브러리 `csv`로 읽는다. 열 이름은 `size`, `length_m`.
3. `length_m`이 비었거나 숫자로 바꿀 수 없으면 `경고: <행 번호>행 길이 값 없음 — 제외`를 출력하고 그 행은 더하지 않는다.
4. 관경은 `"` 앞의 숫자로 정렬한다(작은 것부터).
5. 출력 형식: 한 줄에 `<관경>\t<합계 m, 소수 1자리>`, 마지막 줄 `합계\t<전체 합계>`.

## 3. 하지 말 것
- 위 두 파일 밖은 고치지 않는다.
- 외부 패키지(pandas 등)를 쓰지 않는다.
