# 검토 — 배관 자재 목록에서 관경별 길이 합계 내기

- 검토: Claude (보고서 + 변경 내용 대조)
- 결론: **통과 (지적 1건 — 사용자 판단 필요)**

## 1. 보고서 주장 ↔ 근거
| 주장 | 근거 | 판정 |
|---|---|---|
| V1 합계 일치 | 직접 실행해 같은 출력 확인 | 확인 |
| V2 빈 길이 행 제외 | 직접 실행. 경고의 행 번호가 머리글을 1행으로 센 값(3행 = L-102)임을 확인 | 확인 |
| V3 사용법·종료 코드 2 | 코드 첫 부분 `sys.exit(2)` 확인 | 확인 |

## 2. 지시서 범위
- 바뀐 파일 2개 모두 지시서 대상 안. 외부 패키지 없음.

## 3. 지적
1. **관경 없는 행을 `(관경 없음)`으로 합계에 넣는다** — 지시서에 없던 동작이다.
   계획서의 「맞는 결과」는 "값이 이상한 행은 경고와 함께 제외"였다. 관경이 빈 행도 같은 원칙이면 제외가 맞다.
   → 사용자 판단: 지금 동작을 둘지, 경고 + 제외로 바꿀지.

## 4. 사용자 판정
- `[통과 / 되돌림 — 사용자가 적음]`
