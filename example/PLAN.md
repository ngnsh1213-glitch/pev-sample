# 계획서 — 배관 자재 목록에서 관경별 길이 합계 내기

- 작성일: 2026-12-01
- 상태: 승인 (사용자 승인 2026-12-01)

## 1. 목표
배관 자재 목록(CSV)을 받아 관경별 길이 합계를 표로 낸다. 지금은 엑셀에서 손으로 필터·합계를 내고 있어 매번 10분가량 걸리고 누락이 생긴다.

## 2. 「맞는 결과」 기준
- [ ] `sample.csv`(5행)에서 2" = 20.5 m, 4" = 25.5 m, 6" = 3.2 m, 합계 49.2 m
- [ ] 길이 칸이 비었거나 숫자가 아닌 행은 합계에 넣지 않고 **행 번호와 함께 경고**로 출력
- [ ] 관경 순서는 작은 것부터

## 3. 범위
| 고칠 것 | 고치지 않을 것 |
|---|---|
| `sum_by_size.py` 새로 만듦 | 원본 CSV(읽기만) |
| `sample.csv` 새로 만듦(시험용) | 다른 스크립트 |

## 4. 방법
1. CSV를 읽어 `size`별로 `length_m`을 더한다(표준 라이브러리 `csv`만 사용).
2. 관경 문자열 `2"`에서 숫자를 뽑아 정렬 기준으로 쓴다.
3. 결과는 화면에 표로 출력한다.

## 5. 검증 방법
- `python sum_by_size.py sample.csv` → 위 2절 숫자와 일치
- 길이 칸을 비운 행을 하나 넣은 파일 → 경고 1줄 + 그 행 제외 합계

## 6. 위험·확인 필요
- 실제 목록의 관경 표기가 `2"` 말고 `50A`인 경우가 있는지 → `[확인 필요]` 이번에는 `"` 표기만 다룬다.
